      Outras operações

      Copie o conteúdo de uma tag para outra, apague ou bloqueie para sempre.

      Copiar tag

      Lê todos os registros de uma tag e grava a mesma mensagem em outra.

      Apagar conteúdo

      Substitui a mensagem da tag por um único registro vazio. A tag continua gravável.

      Bloquear permanentemente

      Deixa a tag somente leitura. É irreversível: nunca mais será possível gravar nela.
